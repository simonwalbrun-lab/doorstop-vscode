# Quickstart: Hover Previews & Navigation

Automated: `npm run test` (VS Code integration tests, regression fixture; runs in CI).
Look for the hover and auto-reveal tests tagged `Spec 006 FR-NNN`.

Manual: open the Extension Development Host on the fixture; (1) hover `REQ-001` in `REQ-010.yml` -> title/level/text; (2) hover `derived:` in `REQ-001.yml` -> `ARCH-001` listed; (3) click a popup link -> file opens and the tree reveals it (auto-reveal on).
